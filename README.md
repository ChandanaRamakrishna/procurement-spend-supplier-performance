# Procurement Spend & Supplier Performance Dashboard (Power BI)

> **All data in this project is synthetic.** It was generated with `generate_data.py` (fixed seed 42) and does not represent any real company or supplier.

A Power BI report that shows a procurement team where the money goes, which suppliers deliver late, whether prices match contracts, how dependent the company is on a few suppliers, and whether the data can be trusted.

## Questions it answers
- How much are we spending, and on what?
- Which suppliers deliver late, and by how many days?
- Are we paying more than the contract price?
- Are we too dependent on a few suppliers?
- Are there duplicates and errors in the data?

## Data
Generated by `generate_data.py`:
| Table | File | Rows |
|---|---|---|
| Purchase orders | `data/purchase_orders.csv` | 2,040 (2,000 + 40 duplicates) |
| Suppliers | `data/suppliers.xlsx` | 25 |
| Items | `data/items.csv` | 60 |

Deliberate problems planted: duplicate POs (40), missing suppliers (30), negative quantities (20), delivery before order date (25, plus 3 inside duplicate copies), and about 25% of POs priced off contract.

`validate_data.py` recomputes the main numbers in pandas as an independent check on the Power BI results.

## Method
1. **Python**: generate the data (reproducible).
2. **Power Query**: types, duplicate numbering, validity flags with an `IssueReason`, `DelayDays` (actual - promised), `LeadTimeDays`, `LineAmount`. Valid rows go to `FactPO`; all rows stay in `DQ_Log` for the Data Quality page.
3. **Model**: star schema, `FactPO` linked to `DimSupplier`, `DimItem` and `DimDate` (marked as date table). Time is based on order date.
4. **DAX**: see `dax/measures.dax`.

## Measures
| Measure | Definition |
|---|---|
| Total Spend | Sum of quantity x unit price on valid POs |
| PO Count | Distinct PO IDs |
| On-Time % | POs delivered on/before the promised date / all POs |
| Average Lead Time | Mean days from order to actual delivery |
| Average Delay Days | Mean of actual - promised (negative = early) |
| Spend MoM % | (Spend - prior month spend) / prior month spend |
| Price Variance vs Contract | Spend - quantity x contract price |
| Off-Contract Spend % | Spend on POs where price differs from contract / total spend |
| Top-5 Supplier Share | Spend of the five largest suppliers / total spend |
| Supplier Rank | Rank of supplier by spend |

## Limitations
- Synthetic data: patterns come from my generator's assumptions, not real behavior.
- Invalid rows are excluded, not corrected; real data would need a fix-at-source process.
- Single currency, no partial deliveries, no invoice or payment data.
- Time analysis uses order date only.

## How to reproduce
```bash
pip install -r requirements.txt
python generate_data.py
python validate_data.py
```
Open `Power BI Projects.pbix`, or rebuild it following `docs/BUILD_GUIDE.md` (set the `DataFolder` parameter to your local `data\` path).
